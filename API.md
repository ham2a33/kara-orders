# API

## Base URL

- Local: `http://localhost:8000/api/v1`
- Production: reverse-proxied through Nginx

## Key Endpoints

- `GET /health/live`
- `GET /health/ready`
- `POST /auth/register`
- `POST /auth/login`
- `POST /auth/refresh`
- `POST /auth/logout`
- `GET /companies/me`
- `GET /products`
- `GET /orders`
- `GET /dashboard`
- `GET /analytics/revenue`
- `GET /platform/subscriptions/me`

## Documentation

- Swagger UI: `/docs`
- OpenAPI JSON: `/openapi.json`
